📋 OPCIÓN A: Content App (Más Simple)

Descargar versión Markdown

Pasos:

  1. Ve a tu Whop Dashboard
  2. Apps → Add App → Content
  3. Copia y pega el contenido del archivo .md
  4. Whop formatea automáticamente:
    • # Títulos → Headers
    • - [ ] → Checkboxes interactivos
    • | Tablas | → Tablas automáticas
    • > Quotes → Bloques de cita
  5. Agrega imágenes manualmente donde necesites
